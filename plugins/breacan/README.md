# breacan

Agent skills for Breacán: `make-kit` makes or changes a kit, and `use-kit` puts a kit's outputs into an app and keeps the app on them with `breacan lint`. Install from the Breacán market in this repo (`claude plugin marketplace add kickinrad/breacan`, then `claude plugin install breacan@breacan`; in Codex, `codex plugin add`). The engine itself installs with `mise use github:kickinrad/breacan`.
