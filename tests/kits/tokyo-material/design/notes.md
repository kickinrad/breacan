# Tokyo Material

## Character

Wils's default UI kit: Material 3 on the Tokyo Mono palette, Tokyo Night accents on Windows 11 Fluent 2 greys. Every Material component is here; a difference from Material 3 is a named exception that says why.

## Rules

- Keep it neutral; colour means state. Text and marks on a container use its on-container colour.
- Set names and labels in the brand face, and code and numbers in the mono face with tabular figures.
- Name the thing, not its condition. Write in sentence case, and say a fact once.
- Move only with Material's motion tokens; under reduced motion, nothing moves.
- A screen follows the kit's rules and adds none of its own.
